名词表
======

OpenFoD
  开源重铸项目，以及 Godot 客户端所在的游戏仓库。

《傲世三国》 / Fate of the Dragon
  2001 年原作。OpenFoD 不发行其商业数据。

城中之城
  战略图上的城与城内经营图叠在同一战区里的设计。

翰林院
  科技建筑。升级后解锁更高级建筑与二、三级科技。

Parity
  用同一份场景脚本分别驱动新旧引擎，并对比 transcript 的对照方法。

``FOD_GAME_ROOT``
  指向本机原版安装目录的环境变量，只用于开发与解码测试。

psdocs
  本站使用的 Sphinx 主题名（布局来自 GitHub Docs 风格的参考实现）。品牌文案已改为 OpenFoD。
