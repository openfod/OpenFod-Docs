武将与招揽
==========

文官治城，武将破阵。三国的故事不在数值表里，而在人心向背。

客栈
----

客栈招募武将，不耗民夫，耗钱。同时最多 3 名待招武将，并定期刷新；门外灯亮表示有人。需要翰林院升过级才能建造客栈。

人物类型
--------

原作人物表从具名武将开始记录曹操、夏侯惇、吕布、诸葛亮等三百余人，并与民夫、士兵、器械共用同一套实体结构，用类型位区分。三类人物是：

- **武将**：可上阵、可单挑、可劝降
- **文官**：偏重内政
- **异人**：特殊角色，不能上马

忠诚
----

赐爵、赏赐与宝物维系忠诚。忠诚影响生产与战斗效率。战场上可以单挑，也可以劝降。流失一名核心武将，往往比拆掉一座兵营更伤。
