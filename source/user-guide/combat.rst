野外、攻城与巷战
================

战事分成三层：郊外野战、城墙攻防、破门之后的巷战。粮道一断，再强的军阵也会溃散。

选择与命令
----------

操作是经典即时战略：左键选择，右键下令，拖框多选。选中民夫时脚下是绿圈，选中建筑是矩形框。

命令来自一张约 100 个 ID 的动作表，界面只是这些动作的皮肤。高频动作包括：生产、建造、拆除、修理、招募、研究、买卖、上下马、上下船、扎营，以及攻城器械与外交。

兵种
----

步兵三条线：刀、枪、弓。必须由民夫进入对应兵营训练，并消耗资源。

骑兵不是单独兵种：步兵或武将右键马匹即可上马。文官和异人不能上马。

状态条
------

- 头顶蓝条是 **体力**。己方城内进食恢复；城外随时间下降。降到 0 后训练度开始掉。体力与训练度都影响攻防。
- 脚下绿条是 **生命**。城内用酒恢复。盟友城内可以吃饭回体力，但不能用酒回生命。
- 国家祭祀可立刻恢复体力与生命。

器械与水战
----------

攻城常用云梯、投石、弩车、霹雳车。水战有草船、楼船、码头停靠与上下船。行营可以扎营、拔营、出营，并把物资运往城市或行营。

外交
----

外交五件套：结盟、解盟、进献或进贡、支援、离间。它们和内政官职、武将忠诚缠在一起，不是独立的“胜利屏幕按钮”。
