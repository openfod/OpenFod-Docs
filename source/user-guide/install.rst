安装与启动
==========

系统需求
--------

- 64 位 Windows、Linux 或 macOS
- 能运行 Godot 4.7 客户端的显卡与驱动
- 不必安装 DirectX 7 或原作宽屏补丁

获取客户端
----------

优先使用 GitHub Releases 中的平台包。没有正式包时，从 :doc:`/quickstart` 的开发者步骤自行编译。

启动之后
--------

1. 选择语言（中文 / English，与官网、文档站的语言开关独立存储）。
2. 进入战役、遭遇战或教程。原作有魏、蜀、吴三条战役与新手训练关；OpenFoD 按同等结构重做。
3. 同一战区最多 8 座城。底部城市按钮用于在城内图与战区图之间切换。

不要做的事
----------

- 不要把破解补丁、``ali213.bin`` 或来路不明的 ``sanguo1920.exe`` 当成 OpenFoD 的一部分。
- 不要把原作 ``Res/``、``Dialog/``、``Scns/`` 提交或上传到任何 OpenFoD 仓库。
- 分辨率与窗口化由现代客户端处理，不再依赖 2001 年的第三方补丁。
